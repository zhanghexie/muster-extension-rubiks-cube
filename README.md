# 魔方

Muster extension `rubiks-cube`; migrated from `zhanghexie/muster@f049b476`.

- Installable source directory: `rubiks-cube/`.
- Versioned installation artifacts: `releases/`.
- [Muster extension catalog](https://github.com/zhanghexie/muster-extension-index).

See [extension documentation](rubiks-cube/README.md).

Run `npm ci` and `npm run build` at the repository root to rebuild the checked-in `ui/` files.

Run `npm ci` and `npm test` to run the extension regression tests.
